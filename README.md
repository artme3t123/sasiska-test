# Skolas piekļuves un kavējumu demo

Ļoti kompakts skolas projekts vienā `index.html` failā.

## Funkcijas
- Kartes skenēšanas simulācija (`CARD-1001`, `CARD-1002`, ...).
- Ieejas/izejas žurnāls ar laiku.
- Kavējumu pievienošana skolēnam.
- Vienkāršs administrācijas panelis.
- Datu glabāšana pārlūkā (`localStorage`).

## Kā palaist
1. Atver failu `index.html` pārlūkā.
2. Vai palaid lokālu serveri:
   ```bash
   python3 -m http.server 8000
   ```
   un atver `http://localhost:8000`.

## Piezīme
Šis ir demo mācību projekts, nevis droša produkcijas sistēma.
